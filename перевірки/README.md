# ПЕРЕВІРКИ

Скрипти, які перевіряють ядро програми на числах, а не на вигляді екрана.
Кожен запускається окремо портативним рантаймом із кореня продукту:

```text
runtime\python.exe -X utf8 "перевірки\словник.py"
```

Виходить із кодом 1, якщо хоч одна перевірка провалилась.

**Правило цієї теки: зелене перевіряє щасливий шлях, червоне перевіряє
перевірку.** Механізм тривоги, якого не бачили в стані тривоги, — це напис,
а не механізм. Тому в кожному скрипті є розділ, де ворота навмисно годують
битими даними й дивляться, чи вони справді спрацюють.

Даних господарств тут немає і бути не може: перевірки або самі будують
потрібне, або працюють на синтетиці. Те, що вимагає справжнього поля,
лишається ручним прогоном і записується в `DAILY_LOG.md`.

| Скрипт | Що перевіряє |
|---|---|
| `словник.py` | словник атрибутів: картки, одиниці, ворота на розкладку, звірка з тим, що програма пише у файли |
| `зупинки.py` | чи відрізняють ворота «стояв» від «швидкість не записана»; обидві частоти запису монітора |
| `звірка_з_вагою.py` | чи не роздуває підгін карту на воду, коли вологість числа господарства не названа |
| `ширина.py` | робоча ширина з геометрії проходів на підкладеному перекритті відомої величини |
| `вирівнювання.py` | смугастість проходів: чи знімається підкладений зсув, чи не стирається саме поле, чи не рушиться рівень |
| `аномалії.py` | огріх комбайна за свідком-рослинністю: чи не знімається бідний ґрунт |
| `просторові_викиди.py` | третій крок стандартного протоколу: точки, що суперечать сусідам. Головне червоне — справжня низина не зʼїдається |
| `звіт_у_віддачі.py` | звіт складає той самий прогін, що й shapefile; жодного аргументу без діла; ворота звіту читають ЗАПИСАНИЙ PDF, а не лічильник у памʼяті |
| `розкладка_звіту.py` | сторожа переповнення в стані тривоги: завідомо завелика картинка · КВАДРАТНЕ поле, на якому ламався вгаданий коефіцієнт висоти · підписи шкали, що налазять · жодна картинка не кладеться повз вимірювач |
